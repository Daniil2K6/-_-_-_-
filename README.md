# ServiceMonitor

Консольное приложение для проверки доступности интернет-сервисов и мониторинга собственных сайтов.

## Назначение

Быстро проверять, какие сервисы доступны, а какие заблокированы или лежат — не по новостям, а по факту пинга. Дополнительно позволяет мониторить собственные сайты и перезапускать их при необходимости.

## Целевая аудитория

- Пользователи, которым нужно знать доступность сервисов (YouTube, Discord, Telegram и др.)
- Веб-мастера, которым нужен мониторинг собственных сайтов
- Разработчики, которым нужна быстрая проверка инфраструктуры

## Предметная область

Мониторинг доступности веб-сервисов: проверка HTTP-статусов, отображение результатов, управление списком отслеживаемых сервисов.

## Основные сущности

- **Сервис** — название, URL-адрес для проверки, описание
- **Результат проверки** — статус (доступен/недоступен), код HTTP-ответа
- **Список сервисов** — хранилище отслеживаемых сервисов (отдельные .py файлы в папке services/)

## Основные функции

1. Проверка доступности всех сервисов одновременно
2. Проверка отдельного сервиса по выбору
3. Отображение списка сервисов (название, URL, описание)
4. Добавление нового сервиса для мониторинга
5. Удаление сервиса из списка

## Структура проекта

```
service-monitor/
├── README.md           — документация проекта
├── .gitignore          — игнорируемые файлы
├── main.py             — точка запуска, меню, основные функции
├── services/           — папка с сервисами
│   ├── youtube.py      — YouTube
│   ├── discord.py      — Discord
│   ├── telegram.py     — Telegram
│   ├── yandex.py       — Yandex
│   ├── gazprom.py      — Газпром
│   ├── apple.py        — Apple
│   ├── google.py       — Google
│   └── fortnite.py     — Fortnite (Epic Games)
└── docs/               — учебные материалы (в .gitignore)
```

Каждый сервис хранится отдельным Python-модулем с переменными `name`, `url`, `description`. При запуске модули динамически загружаются через `importlib`.

## Запуск

```bash
cd service-monitor
python3 main.py
```

## Меню

```
=== ServiceMonitor ===

1. Проверить все сервисы
2. Проверить сервис выборочно
3. Показать список сервисов
4. Добавить сервис
5. Удалить сервис
6. Выход
```

- **Пункт 1** — пингует все сервисы и выводит статус
- **Пункт 2** — показывает список, вводите номер — обновляется только один
- **Пункт 3** — выводит название, URL и описание без проверки
- **Пункт 4** — создаёт новый .py файл в services/
- **Пункт 5** — удаляет .py файл сервиса

- **urllib** — проверка доступности по HTTP (стандартная библиотека)

- **os** — работа с файловой системой
